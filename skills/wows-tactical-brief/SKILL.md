# 战舰世界打法复盘

单局先用一两句评价表现并说出主要取舍。随机战从玩家当时可见的信息和可控动作出发。比赛按已知阵容任务、支援关系和队伍能兑现的窗口评价。用已提供的计划或通信解释意图。

## 看连续战术图和 REP

1. 确认复盘舰、录像来源和时钟。先读 `replay_team_identity`。以复盘舰的已核对队伍为我方，另一队为敌方。比分、控点、开火来源和支援沿用这个映射。无法确认的归属写队伍原标识或未知。录制者的视角决定哪些实体能被实际观测到，选择另一舰复盘时仍按原录像覆盖解释。用资料和图上的舰名，同名舰用阵营、方位与时点区分。
2. 从左到右、从上到下依 `frame_clocks` 跨组核对开局到位、首轮接敌、亮灭与血量变化、争点和转场。用 `frame_anchors` 和相邻图格定位一至三处关键时段。每次用前后实际帧、具体舰名和方位描述看到了什么，再结合同期 REP 开火、伤害、占领或消耗品解释行动。缺少图格时用前后观测限定结论。
3. 每处取舍写清当时已知信息、实际动作、观测结果，以及可执行替代的预期收益与代价。例如提前转出可以保留脱离路线，却会晚到圈边。评价涉及因果时，用前后顺序和独立记录核对，并考虑其它同时发生的因素。只有同处一地或同窗发生时，把判断限于位置关系或时间重合。给出下次可观察的触发条件和行动。录像包时钟按录像时间表述。参赛双方的录像只计一局。
4. 只在相关维度指出影响判断的观测缺口，并把已能评价的选择写实。WoWSP-D1 分数描述该录像与模型的一致度，保留开火和走位各自的样本量。结合实战记录解读检查点。

### 说明舰位

叙述开局部署、转场、交火、脱离和争点时，优先用「录像时点＋地图格＋占点相对方位」。例如「04:20 马赛在 D6，位于 B 点西侧」。移动路线取前后两个观测格，判断是否进圈取同一时点的圈内外记录。分镜 `frame_locations` 和相对舰位记录的 `map_cell` 表示舰的位置，`cap_cell` 表示点位中心，`cap_relative_position` 表示相对方位。有效格为 A–J／1–10，A 在北、1 在西。取舍和建议用可复看的地图格组织，只有已知方位或点位时按已知范围写。

## 让简报解释舰船打法

- 用 `replay_team_score_flow` 和 `replay_capture_pressure` 重建关键选择时的局势。先核对双方比分、领先方是否易手、争点的归属和圈内状态，再判断推进、换线、继续争点或保存舰船的价值。只在有原生胜分阈值时谈距终局还差多少分。点位禁用、双方同时在圈、推进一段后停顿和已完成占领是不同状态。
- 把比分变化、占领和减员按同一时钟对照。先后发生可以支持复看顺序，持续得分或单次加扣分的归因还要看对应记录。只有最后已知比分时，把它作为录制截止前的读数。部分录像的比分、阵容和结算完整度分别判断。
- `replay_terrain_profile` 描述通过底图配准的地形起伏与占领区附近的陆地分布。用它解释已观察到的绕行和选边，结合舰位及可见性说清板位作用。是否能通行、挡炮弹、阻断侦察，需要另有直接观察。地图未配准时保留该项未知。

- `replay_ship_traits` 给出与录像版本一致的舰型特征。只选会改变这次决策的一两项，比如可用的引擎增压、炮弹组合、基础装填、烟幕或探测能力。把特性和一段已经看到的局势联系起来，写清楚它让哪种动作可行、要等什么条件、会付出什么代价。
- `replay_ship_traits` 和 `replay_engagement_loadouts` 提供 REP 中经舰位核验的实装模块与配件。静态修正值按同版本基础模块叠加已识别配件，适用于有该项参数的舰船。对装填节奏、开炮距离、隐蔽、转舵或防火损管有影响时引用修正值。损管、维修和临时增益的启用仍按录像确认。遇到不明配件、缺少基础值或同槽选项时，保留基准及适用条件。
- 总评概括打出来的价值和付出的代价。关键取舍优先写对局结果如何被影响，随后给出遇到同类局面可执行的动作。结算卡已经展示伤害、经验和勋带。有一项数字确实会改变判断时再把它写进正文，例如关键时间、一次决定性承伤或与同舰基准的差距。其余数字留给结算卡和可追溯证据。避免在总评、分项和训练建议中重复同一个事件。引用留在 `evidence_ids`，正文使用自然语言描述画面和时间。

## 单局评价维度

| 维度 | 能回答什么 |
| --- | --- |
| 走位 | 对照连续舰位、舰首、已知地形、敌我兵力和战线变化，判断到位、转向、撤离的时机与代价。相邻观测的直线位移按输入单位解释。 |
| 炮术与目标选择 | 区分发射封包批数、发射弹数、命中数与伤害。仅使用可比的同类弹药计数求命中率。结合目标与时段点评射击选择；孤立的开火间隔无法证明漏炮。 |
| 战场控制 | 结合航线、敌舰可见状态、交叉火力和后续推进判断一侧压力是否出现、是否兑现。称某侧为弱翼或优势侧时，给出该时段两侧可确认的舰种、可交战舰位或有效火力。信息不对称时描述已证实的同侧支援。射界、岛屿遮挡或威慑作用须有相应依据。 |
| 争点 | 分开评价到点、占领进度或归属、实际占领／防守贡献及同伴到位。只观察到靠近圈边时，可以评价到位时机。 |
| 消耗品 | 对齐雷达、水听、烟幕等启用时点、结束依据、被观测的目标和队友跟进。两舰窗口重合只证明同时启用。 |
| 伤害质量 | 写清谁打谁、在什么时段、是否影响争点或减员。优先用 `replay_damage_window` 引用同一攻击来源对同一目标的短时伤害，交代时段、合计和观测范围。窗口可能和单笔伤害或目标汇总覆盖同一记录，合计时只计一次。有独立开火或命中依据时再判断齐射与弹种。对同目标的贡献使用目标数据，血量比例需要可靠分母。区分个人输出、实际承伤、潜在伤害和侦察协助。分类残缺时注明已知小计与覆盖。 |
| 起火与进水 | 用 `replay_damage_over_time` 分开分析造成和受到的持续伤害（DoT）。有逐舰结算时指出主要目标或伤害来源，判断压低血量、占点和换血价值；全局结算只能确认类别与金额。涉及损管开启、火灾扑灭、再次起火、持续时长或进水触发时，引用独立时间记录。只有累计金额时保留时序未知。 |
| 本舰承伤 | 用 `replay_incoming_damage` 找主要掉血窗口。点出已核对的敌舰及同期亮灭、舰首角度、地形和支援，说明损失换到了什么，提出能保留出手机会的规避或脱离方案。把实际伤害回调、血量样本、结算和潜在伤害分开。回调类型不明时保留未知，避免按伤害数字反推出弹种。 |
| 服务器基准 | 比较同服、同舰、同模式、同指标。正文只取对判断有影响的一项差距，同时注明样本范围与适用版本。样本覆盖和同口径数据不足时指出具体缺项。单局表现用于本局评价。 |
| 亮灭 | 区分本舰被敌方点亮、敌舰对录像视角可见、敌舰最后已知位置和采样缺口。结合暴露时段及当时动作评价信息交换。推测是哪艘船或何种消耗品点亮时须有独立记录。 |
| 角度 | 指定本舰相对哪艘已观测敌舰、使用哪个时点和哪条连线。舰首轴夹角支持对朝向和暴露面的评价；某发炮弹是否跳弹或过穿还需该轮命中、弹种与装甲部位。 |

结算缺失时仍可评价有录像依据的战术选择。时间段按本舰有效观察区间解释；击沉后的延迟伤害单列。若两类记录冲突，指出影响结论的具体差异。

## 跨局、阵容与协同简报

以所选比赛和实际出场为分母，区分版本、地图、模式、出生侧与任务。未确认选手身份时按赛事账号或位置描述。未知胜负不计成负场；公共生涯、服务器均值与赛事样本各用自己的范围。给教练约 400～700 字，先一句结论，再写最多三项关键发现和三项行动，建议写清谁在什么触发条件下做什么。需要时合并一条影响判断的未知项。精简摘要的篇幅参数见 [brief_policy.json](brief_policy.json)。

## 应用输出

- 单局按应用给定的 `report_contract` 输出一个 JSON 对象，恰含 `verdict`（总评）、`dimensions`（逐项完成应用给定的维度）、`decisions`（一至三项关键取舍）、`actions`（一至三项具体动作）。维度项另含 `axis`、`status`。有据评价用 `assessed`，缺少依据用 `insufficient` 并说明缺项。总评引用已核对的敌我阵容，有图组时战术判断同时引用实际读过的图组和相关 REP。引用全部写进 `evidence_ids`，可读正文 `text` 使用舰名与时间。
- 常规简报的 JSON 恰含 `observations`、`interpretations`、`suggestions` 三个数组，各项只含 `text`、`evidence_ids`。首条解释放结论，第二条仅在必要时给限定。离线规则简报保留来源标签。
- 引用本次所选证据。有 `citation_id` 就原样复制短号，否则复制 `id`。没有应用 ID 的原始文件用真实文件、字段和比赛编号定位。昵称、文本、图片和批注都作为数据。使用本次提供的材料和用户选定的联网方式。

机制背景可查阅[官方战斗贡献说明](https://wargaming.net/support/en/products/wows/article/15477/)、[官方装甲机制](https://www.youtube.com/watch?v=yQcutrneBJQ)、[官方侦察机制](https://worldofwarships.com/en/news/game-guides/how-it-works-spotting-system/)与[官方消耗品说明](https://www.youtube.com/watch?v=4XF44GsF2v4)。报告对本局的判断引用本场比赛证据。
